SkySense AI

React Node.js Groq · Llama 3 Amadeus

An LLM-powered flight assistant that parses natural-language travel queries, searches Amadeus and Google Flights in parallel, and generates Razorpay payment links for instant booking — with seat maps and airline filters baked in.

Git Sense

React FastAPI RAG ChromaDB

An AI code-analysis tool that ingests any GitHub repo, builds a vector index over the codebase, and answers questions about architecture, security, and quality — with auto-generated READMEs you can push back to the repo.

DocSense

React FastAPI Qdrant Groq

A private RAG chat app for your local documents (PDF, DOCX, TXT) with Qdrant vector storage, multi-model support across Llama 3.3 and Mixtral, and auto-suggested questions per upload.

PromptSense
