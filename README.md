# Portfolio — Palani Prashanth

Personal portfolio site. Static HTML/CSS/JS, no build step.

## Pages

- `index.html` — home (hero, bio, project log, skills)
- `work.html` — experience timeline + full project log
- `wows.html` — side projects, writing, hackathons
- `contact.html` — links to GitHub, LinkedIn, X, email + resume

## Run locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000

## Stack

- Plain HTML5 + a single `styles.css`
- Google Fonts: Instrument Serif (body) + Pixelify Sans (headings)
- `bg.webp` for the cover image

## Deploy

Drag the folder into Vercel, Netlify, or GitHub Pages — no config needed.
